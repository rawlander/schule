So arbeitest du

Dein Kurs in vier Stufen

  1. 1Aufträge und AnfragenIch schreibe Aufträge und Anfragen, die Attribute verändern oder abfragen.
  2. 2Werte rein, Ergebnis rausIch schreibe Methoden mit Parametern und Rückgabe und prüfe sie mit Testfällen, auch Grenzfällen.
  3. 3Sportwagen, Van, SpeedbootIch ergänze eine Unterklasse mit super-Aufruf und überschreibe Methoden mit und ohne super.
  4. 4Die ganze FlotteIch durchlaufe ein Array von Objekten, um zu summieren, zu zählen, zu suchen und das Maximum zu finden.

Jede Stufe endet mit einem Plateau: Das erreichen alle, bevor es gemeinsam weitergeht. Expert-Aufgaben sind freiwillig.

Stufe 1 · Methoden

Aufträge und Anfragen

Was merkt sich ein Mietwagen, und wie fragt man ihn?

Merke Ein Objekt hat Attribute (was es sich merkt) und Methoden. Aufträge (void) verändern Attribute, Anfragen geben mit return eine Antwort. Beim Rover waren die Attribute versteckt – jetzt schreibst du sie selbst.

Klassenkarte und Beispiel

  • - akku : int
  • - akkuGroesse : int

  • + ladeBalken()
  • + verbraucheBalken()
  • + ladeKomplett()
  • + istInGarage() : boolean
  • + istVoll() : boolean
  • + istLeer() : boolean
  • + anzeigen()
public boolean istInGarage()
{
    return position == 0;
}

So sieht eine fertige Anfrage aus. Baue istVoll() und istLeer() genauso.

Stufe 2 · Parameter

Werte rein, Ergebnis raus

Wie sage ich dem Auto, wie viel es laden soll – und was wurde wirklich geladen?

Merke Ein Parameter bringt einen Wert in die Methode (int pAnzahl). Mit einem Rückgabetyp wie int liefert sie ein Ergebnis zurück. Zwei Methoden dürfen gleich heißen, wenn ihre Parameter verschieden sind (Überladen).

Klassenkarte und Beispiel

Auto
  • …
  • - geschwindigkeit : int
  • + fahreBloecke(pAnzahl : int)
  • + gibFreieBalken() : int
  • + ladeBalken(pAnzahl : int) : int
  • + verbraucheBalken(pAnzahl : int) : int
  • + berechneFahrzeit(pKilometer : int) : int
  • + schafftStrecke(pKilometer : int, pStunden : int) : boolean
Auto a = new Auto("Flamingo GT", 10, 60);
a.ladeBalken(4);             // liefert 4
a.ladeBalken(9);             // nur 6 frei: liefert 6
int h = a.berechneFahrzeit(121);  // 3 Stunden

So wird getestet. Leite die Werte erst selbst her, dann starte den Prüfstand.

Was liefert ladeBalken(9), wenn nur 6 Balken frei sind?

6 – es wird nur geladen, solange Platz ist.

Wie lange braucht ein Auto mit 60 km/h für 121 km?

Stufe 3 · Vererbung

Sportwagen, Van, Speedboot

Was haben alle Mietfahrzeuge gemeinsam – und was kann nur ein Sportwagen?

Merke Die Oberklasse Fahrzeug enthält, was alle Fahrzeuge gemeinsam haben. Unterklassen erben alles (extends) und ergänzen Eigenes. super(…) ruft den Konstruktor der Oberklasse auf, @Override überschreibt eine Methode – mit super.methode() wird sie erweitert, ohne wird sie ersetzt. abstract: Es gibt kein Objekt, das nur ein Fahrzeug ist.

Klassenkarte und Beispiel

Fahrzeug {abstract}
  • - name : String
  • - position : int
  • - geschwindigkeit : int
  • + fahreBloecke(pAnzahl : int)
  • + berechneFahrzeit(pKilometer : int) : int
  • + gibTyp() : String {abstract}
  • + berechneMiete() : int
  • + anzeigen()
public class Sportwagen extends Fahrzeug
{
    @Override
    public int berechneMiete()
    {
        return super.berechneMiete() + ps / 2;
    }
}

Sportwagen ist die fertige Musterklasse. Lies sie zuerst, dann ergänze Van.

Nr.AufgabeDas hilft
3.1Van: Konstruktor ergänzen (super(…) steht schon da).wie Sportwagen
3.2gibTyp() überschreiben.Pflicht-Override
3.3einsteigen(int pAnzahl): höchstens so viele, wie Sitze frei sind.wie ladeBalken(int)
3.4alleAussteigen(): Anzahl merken, auf 0 setzen, zurückgeben.Hilfsvariable

Check dich selbst

Warum darf man nicht new Fahrzeug(…) schreiben?

Fahrzeug ist abstrakt – es gibt nur Sportwagen, Vans und Speedboote.

Was liefert f.gibTyp() bei Fahrzeug f = new Van(…)?

"Van" – entscheidend ist das Objekt, nicht der Variablentyp (Polymorphie).

Stufe 4 · Arrays

Die ganze Flotte

Wie verwaltet Palm Bay Rentals viele Fahrzeuge auf einmal?

Merke Ein Array ist eine Reihe nummerierter Stellplätze: Fahrzeug[] flotte = new Fahrzeug[10];. Die Zählung beginnt bei 0. anzahl zeigt auf den nächsten freien Platz. Weil Sportwagen, Vans und Speedboote alle Fahrzeuge sind, passen sie in dasselbe Array.

Klassenkarte und Beispiel

Autovermietung
  • - name : String
  • - flotte : Fahrzeug[]
  • - anzahl : int
  • + hinzufuegen(pFahrzeug : Fahrzeug) : boolean
  • + alleAnzeigen()
  • + alleFahren(pBloecke : int)
  • + berechneGesamtmiete() : int
  • + zaehleTyp(pTyp : String) : int
  • + sucheFahrzeug(pName : String) : Fahrzeug
  • + gibSchnellstesFahrzeug() : Fahrzeug
  • + sortiereNachGeschwindigkeit()
public void alleAnzeigen()
{
    for (int i = 0; i < anzahl; i++)
    {
        flotte[i].anzeigen();
    }
}

Das Muster für fast alle Aufgaben: das Array mit einer for-Schleife durchlaufen.
